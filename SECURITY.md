# Security Policy

## Supported versions

Security fixes are applied to the latest published version. Development and
prerelease builds are provided for testing and may contain known limitations.

## Reporting a vulnerability

Please do not disclose an unpatched vulnerability in a public issue. Use the
repository's private security advisory/reporting channel on GitHub. Include:

- the affected version or commit;
- the operating system and installation method;
- clear reproduction steps;
- impact and, if available, a minimal proof of concept.

Do not include passwords, API keys, OAuth tokens, cookies, personal profiles,
or database files in a report. Redact sensitive values before attaching logs.

We will acknowledge a valid report, investigate it, and coordinate disclosure
after a fix or mitigation is available.
